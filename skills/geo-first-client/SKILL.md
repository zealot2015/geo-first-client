# GEO 从零到第一单｜Agent Skill

## 触发与模式

在用户提出以下需求时启动：GEO入门、AI搜索优化、品牌被豆包/DeepSeek/ChatGPT提及或引用、GEO案例复盘、做GEO报告、选择GEO服务模式、从零开发GEO客户、78关训练营、对GEO交付进行验收。

首次交流时根据请求选择模式，不需要长问卷：
- **教练模式**：用户想系统学习/训练/闯关/验收。每轮只布置一个具体关卡；进度由本地文件或用户提供的存档决定；没有存档时从 `00-01` 开始。完整教材按需读 [78关目录与每关步骤](references/curriculum-78.md)。
- **执行模式**：用户已有实际业务目标，需要协助诊断、测试、制作内容、报告或报价。按下方工作流执行，可以跨关调用参考资料，但必须记录来源、证据与批准状态。**不要为了执行业务强迫从LV0重练。**

## 核心工作流（两种模式共用）

1. **定义目标及授权**：品牌、目标客户/市场、AI平台、网站情况、是否有合法账号与内容发布授权；匿名演练与真实客户须明确区分。使用 [项目简报](assets/templates/project_brief.md)。未知信息标「未知」，不要编造。
2. **发现真实问题**：收集10～20个客户可能自然提出的问题，分为场景、对比、操作、品牌核查四类；品牌核查题只测准确性，不混入无品牌提及率的分母。查看 [测试协议](references/test-protocol.md) 和模板 `01_问题库.csv`。
3. **建立基线**：在用户有权使用的平台手动/合规地测试，记录问题原文、时间及时区、平台/模型/联网开关、完整回答、来源链接、屏幕证据。不能声称已经访问未实际访问的AI平台。
4. **分别标注指标**：提及、明确推荐、提及顺序、引用网页、事实准确性、访问/询盘单独记录。不要用一个“综合推荐率”代替。可以运行 `scripts/visibility_summary.py` 对 `09_六维可见性标注.csv` 计算*样本内*描述统计；输出要保留缺失分母与方法限制。
5. **竞品与信息来源研究**：逐条核实链接确实存在；寻找可访问性、信息冲突、缺失问答、缺少真实依据、表达不清等问题。不要把模型猜测当成算法内幕。详见 [证据与风险](references/evidence-and-safety.md)。
6. **内容与渠道方案**：先建立真实的品牌事实卡，再选择FAQ、场景选型、技术说明、客观比较等内容。发布渠道依据实测来源和买家场景选择，不采取虚构第三方身份、刷量、伪造榜单/评价。没有授权只做草案/只读检查。
7. **网站分支**：无站走公开信息+内容草案；有站但无管理权限做只读审查；有明确修改授权才能改代码、robots、Schema、索引配置、发布页面，且事前确认方案、回滚及可验证结果。`llms.txt` 不作必要项或效果保证。
8. **复测和报告**：尽量沿用基线问题、平台、时段、模式；保留各轮原始记录，不随意删除负面样本。对比仅说明观察到的变化，不将变化直接归因于GEO。详见 [交付手册](references/delivery-and-business.md)。
9. **商业化**：按工时、工具、第三方与返工成本定价；界定服务范围、交付清单、客户审批、维护责任、数据隐私。**不能保证AI排名、引用、转化或收入。**

## 教练模式：一关一验收

每次任务必须输出：`任务ID/名称 → 用大白话解释 → 在哪操作 → 逐步操作 → 最小演示 → 提交物 → 验收标准 → 风险提示`。复杂动作拆成最多3个连续子动作。用户说“我卡住了”时不跳关。

验收量表100分：理解20、证据与真实性30、执行完整度25、风险及授权15、归档10；**至少85分且无红线**才通过。没有查看的图片、链接、表格、文件不得声称检查过。未交必要证据时标记「待证据」，不要凭空打85分。

通过后输出一个可复制的训练记录：日期、关卡、证据地址、5项分数、是否通过、返工事项、下一关、客户/演示身份及授权状态。模板见 [训练存档](assets/templates/training_state.md)。旧课程的65个ID保持一致，新13关包含在78关中；无证据不假设已通过。

## 执行模式：Agent能做与不能做

- 能做：在现有权限下读取公开网页、提取可信事实、建立问题库、处理用户提供的CSV、生成诊断草案与报告、检查本地文件、在批准后制作/修改代码。
- **需用户明确授权**：登录第三方后台、发布/修改企业官网及社交内容、发送获客消息、购买工具、建立/签署合同、付款及收款动作。
- 不可做：伪造客户评价/认证/榜单、假中立评测、投毒、刷采集、绕过访问限制、批量灌水、凭想象补写截图/数据、泄露私人客户资料。
- 若没有可访问的外部工具：生成可执行的手工步骤或待审核稿；明确“尚未测试/发布/验证”。

## 常用口令

- `开营`：读取已有存档/用户确认进度，首次从00-01开始。
- `下一关`：确保前一关真实通过，再发布正确下一关。
- `提交验收`：审查证据，评分并更新训练存档，不提前发新关。
- `我卡住了`：给不超过3步的具体指导。
- `执行一次GEO诊断`：转执行模式，先做目标和权限边界确认，再出测试计划。
- `做GEO报价/诊断报告`：套对应模板，禁止填入虚构客户案例或测试结果。

## 完成判定

训练结业需要真实证据；首单达成必须有实际客户的合法委托、约定的交付与对应成交证明。未成交时如实记录「未成交」，不发“首单已完成”结论。
